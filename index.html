Installation Guide

Setup JavaGoat

Get the AI forensics engine running on your local machine.

1
Install Python
Terminal command 
winget install Python.Python.3.12
Restart your terminal after installation and verify with python --version
2
Install PyTorch
Standard Installation 
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
3
Install dependencies
Python Packages 
pip install fastapi uvicorn transformers pillow accelerate
4
Download AI Model
HuggingFace CLI 
python -c "from transformers import AutoModelForImageClassification..."
5
Project Structure
your-project/
├── vision_server.py
└── www/
    └── index.php
Ensure index.php is inside your Laragon www folder.
6
Setup PHP Server
Laragon Download 
https://laragon.org/download/
7
Start Vision Server
Run Command 
python vision_server.py
Keep this window open while using the application.
8
Launch Application
Local URL 
http://localhost/index.php

Help & Troubleshooting

Module Not Found
Try running pip install followed by the name of the missing package.
Connection Error
Ensure the Python server from Step 7 is still active and hasn't crashed.
