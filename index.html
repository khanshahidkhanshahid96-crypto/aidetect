Local Setup Guide.

High-visibility instructions for the AI Vision Server.

1
Install Python 3.12
Windows Command 
winget install Python.Python.3.12

Restart terminal and check version using python --version

2
Install PyTorch
Standard Pip 
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
3
Install Dependencies
Command 
pip install fastapi uvicorn transformers pillow accelerate
4
Download AI Model
Direct Download 
python -c "from transformers import AutoModelForImageClassification, AutoImageProcessor; AutoImageProcessor.from_pretrained('umm-maybe/AI-image-detector'); AutoModelForImageClassification.from_pretrained('umm-maybe/AI-image-detector'); print('Ready')"
5
Server Setup (Laragon)
Download link 
https://laragon.org/download/

Drop your index.php into the C:/laragon/www/ folder.

6
Run Vision Server
Run this in terminal 
python vision_server.py
