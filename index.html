1
Install Python (skip if already done)

Open Command Prompt as Administrator and run:

bash
winget install Python.Python.3.12

After installation, close and reopen Command Prompt. Verify it worked:

bash
python --version pip --version
2
Create Project Folder & Virtual Environment
bash
mkdir C:\ai_detector cd C:\ai_detector python -m venv venv

Activate the virtual environment:

bash
venv\Scripts\activate
💡 Your prompt should now show (venv) — that means you're inside the isolated environment.
3
Install Required Python Libraries

Inside the activated (venv), install all required packages for the vision AI and FastAPI server:

bash
pip install torch torchvision pip install fastapi uvicorn transformers pillow accelerate pip install python-multipart
📦 This downloads PyTorch, the web server framework, and ML components. It may take a few minutes — grab a coffee!
4
Create the API Server Script — api.py

In the C:\ai_detector folder, create a file named api.py and paste this exact content:

python
import uvicorn from fastapi import FastAPI, UploadFile, File import torch from PIL import Image from transformers import AutoModelForImageClassification, AutoImageProcessor import io import time app = FastAPI() MODEL_NAME = "umm-maybe/AI-image-detector" device = "cuda" if torch.cuda.is_available() else "cpu" print(f"--- AI Vision Service Starting ---") print(f"Loading model into RAM using device: {device}...") start_load = time.time() # Load model once on startup processor = AutoImageProcessor.from_pretrained(MODEL_NAME) model = AutoModelForImageClassification.from_pretrained(MODEL_NAME).to(device) model.eval() print(f"Model Ready! (Loaded in {time.time()-start_load:.2f}s)") print(f"Service running at http://127.0.0.1:8000") @app.post("/scan-image") async def scan_image(file: UploadFile = File(...)): start_process = time.time() # Read uploaded file contents = await file.read() image = Image.open(io.BytesIO(contents)).convert("RGB") # AI Logic inputs = processor(images=image, return_tensors="pt").to(device) with torch.no_grad(): outputs = model(**inputs) probs = torch.softmax(outputs.logits, dim=-1) ai_prob = probs[0, 1].item() process_time = time.time() - start_process print(f"Scan Completed: AI Prob {ai_prob:.4f} | Time: {process_time:.3f}s") return {"ai_score": ai_prob, "process_time": process_time} if __name__ == "__main__": uvicorn.run(app, host="127.0.0.1", port=8000)
5
Start the AI Service (First run downloads the model)

Still inside (venv) and the C:\ai_detector folder, run the script to start your local AI server:

bash
python api.py
🤖 On first run, it automatically downloads the AI model (~350 MB) from HuggingFace. After this, the API works completely offline.
6
Verify the Server is Running

Wait until you see this success message in your Command Prompt:

output
Model Ready! (Loaded in 2.45s) Service running at http://127.0.0.1:8000 INFO: Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)
⚠️ Do not close this Command Prompt window! Your AI detection engine is now running in the background and waiting for image uploads from PHP.
