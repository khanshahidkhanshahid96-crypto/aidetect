Local Setup Guide

Get it
running locally.

Follow these 8 steps to set up the AI Image Forensics server on your Windows machine.

01
Install Python 3.12
🐍
Windows — winget 
winget install Python.Python.3.12
ℹ After install, restart your terminal and verify with python --version
02
Install PyTorch
🔥
CPU only — safe default 
pip install torch torchvision --index-url https://download.pytorch.org/whl/cpu
NVIDIA GPU — CUDA 12.1 
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu121
03
Install Python dependencies
📦
pip install 
pip install fastapi uvicorn transformers pillow accelerate
04
Pre-download the AI model (~300 MB)
🧠
HuggingFace — umm-maybe/AI-image-detector 
python -c "from transformers import AutoModelForImageClassification, AutoImageProcessor; AutoImageProcessor.from_pretrained('umm-maybe/AI-image-detector'); AutoModelForImageClassification.from_pretrained('umm-maybe/AI-image-detector'); print('Model ready!')"
ℹ Cached to C:\Users\YOU\.cache\huggingface\ — downloads once, reused forever.
05
Place your project files
📁
Folder structure 
your-project/
├── vision_server.py
└── www/
    └── index.php
⚠ Place index.php inside Laragon's www/ folder so the PHP server can serve it.
06
Install Laragon (PHP server)
🌐
Download URL 
https://laragon.org/download/
ℹ Download → Install → Start All → drop index.php into the www/ folder.
07
Start the Python vision server
▶
Run in terminal — keep this window open 
python vision_server.py
✓ You should see: Model Ready! and Service running at http://127.0.0.1:8000
08
Open the app in your browser
🚀
Paste into browser address bar 
http://localhost/index.php
✓ Upload any image → click Analyze Asset → done! 🎉
Quick Troubleshooting
⚠ ModuleNotFoundError
Run pip install <module> for the missing package name shown in the error.
⚠ Connection refused on scan
Python server isn't running. Go back to step 7 and start it.
⚠ Slow first scan
Normal — the model warms up on first inference. Give it ~5 seconds.
⚠ CUDA errors
Set device = "cpu" in vision_server.py and restart.
